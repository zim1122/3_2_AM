# ✅ Show that JavaScript is a Full-Stack Language

JavaScript is called a **Full-Stack Language** because it can be used to develop every part of a web application.

## 1. Frontend (Client-Side)
JavaScript is used to create interactive user interfaces in the browser.

**Examples:**
- HTML
- CSS
- JavaScript
- React.js
- Vue.js
- Angular

## 2. Backend (Server-Side)
Using **Node.js**, JavaScript can also run on the server to handle:
- Business logic
- Authentication
- REST APIs
- Database operations

**Backend Frameworks:**
- Node.js
- Express.js
- NestJS

## 3. Database
JavaScript can communicate with databases using libraries/ORMs.

**Examples:**
- MongoDB (Mongoose)
- MySQL
- PostgreSQL
- Prisma

## Full-Stack JavaScript Architecture

```text
Browser (Frontend)
        │
        ▼
 HTML + CSS + JavaScript
 (React / Vue / Angular)
        │
   HTTP Request
        │
        ▼
 Node.js + Express.js
   (Backend Server)
        │
        ▼
 Database
(MongoDB / MySQL / PostgreSQL)
```

## Popular JavaScript Full-Stack (MERN)

```
MongoDB  → Database
Express.js → Backend Framework
React.js → Frontend Library
Node.js → Runtime Environment
```

## Conclusion

JavaScript can be used for:

- ✅ Frontend Development
- ✅ Backend Development
- ✅ API Development
- ✅ Database Communication
- ✅ Full-Stack Web Application Development

Therefore, **JavaScript is called a Full-Stack Language** because a developer can build an entire web application using only JavaScript.
